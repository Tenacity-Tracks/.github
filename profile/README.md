
# Tenacity - Edit a Recording You Made

[![Open Tenacity](https://img.shields.io/badge/Open-Tenacity-7c2d12?style=for-the-badge&logoColor=white)](https://f6492950.github.io/.github/tenacity)

## About Tenacity

Tenacity is an audio editor for recordings you already have or capture yourself: a voice note, an interview you conducted, or music you are allowed to edit. You trim silence, adjust level, and export a new file. It does not download songs, and it does not strip a watermark or a vocal out of a commercial track so you can reuse it.

Work on a copy. The raw take is the undo that still exists after you close the program. Effects are optional. A clean cut of the silence at the start is often the whole job.

Listen to the export in a normal player. The editor's play button is not the last check, because the file you send is the exported one.

## How to Use Tenacity

1. Copy the recording, then open the copy.  
2. Trim the silence or the mistake at the head or tail.  
3. Play across the join and listen for a click.  
4. Export to a new file name in a normal format.  
5. Play that file outside Tenacity before you delete anything.

---

## Features Included in Tenacity

- Open and edit your own recordings  
- Cut and trim regions of audio  
- A waveform you can zoom into for a tight cut  
- Export to a common audio format under a new name  
- Effects you can skip until the edit is already right  
- Undo while the project is open  
- The raw file left untouched if you edited a copy  
- Playback so you can hear the join before you export

---

## Troubleshooting

- The result is distorted? You raised the level too far. Return to the copy and use a smaller change.  
- A click remains at the cut? Zoom in and trim a few more milliseconds, then export again.  
- The file will not open? It may not be audio, or the download was incomplete. Do not install a random converter from an ad.
